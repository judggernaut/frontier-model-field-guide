The distribution zoo: seventeen shapes and the stories that make them

Seventeen distributions. For each one: the picture, the story that generates it, what it looks like in eval work, and when not to use it. The generating story is the most useful part. If you can match the story, you have found your distribution.

One café, six distributions

Every shape in the zoo comes from a story about how the numbers were made. One morning at a café tells six of them.

One customer either buys a pastry or does not. A single yes/no with a fixed chance (here 30%) is a Bernoulli. In evals: one task, pass or fail.

Count the yeses among 20 customers and you get a binomial: usually around 6, sometimes 2, sometimes 11. In evals: passes out of n tasks.

Count how many people walk in during any 5 minutes, when arrivals are independent and the average is 4: that count is Poisson. In evals: errors per thousand requests.

Measure the gap between one arrival and the next: lots of short gaps, a few long ones, falling away smoothly. That is exponential, with an average of 75 seconds here. In evals: time between failures.

Bill sizes multiply out of several factors (people, items, extras), which makes a right-skewed lognormal: mostly $8 to $15, occasionally a $70 catering order. In evals: latency and token counts.

Average each day's bills and plot 100 days of averages: a symmetric bell, the normal, even though single bills were skewed. That is the central limit theorem from the previous chapter, and why intervals on averages work.

Plain wordsMatch the story, find the shape

Each distribution is the fingerprint of a process. Flip one coin and you get a Bernoulli. Count heads in 200 flips and you get a binomial. Add up many small nudges and you get a bell curve. Multiply many small nudges, like a slow network times a big payload times a cold cache, and you get a lopsided lognormal. You do not need to memorise formulas. You need to ask "what process made these numbers?" and match it to a story below.

For leadersWhy the choice of shape changes decisions

Picking a distribution sounds academic until it changes a ship decision. The common failure is assuming a simple shape when the real process is messier, which makes uncertainty look smaller than it is.

  • Assuming independence that is not there. Treating tool calls inside one session as independent coin flips (binomial) understates uncertainty, often by a factor of two or more. Results look significant that are not.
  • Assuming Poisson for agent counts. Tool calls, turns and retries vary with task difficulty, so variance runs several times the mean. A Poisson model will flag a routine long session as a one-in-a-million event and send engineers chasing noise.
  • Reporting a mean for a heavy tail. For lognormal data the mean describes nobody; for a genuine power law it may not even settle as data grows. Percentiles are the defensible summary.
  • Fitting one shape to a mixture. Two populations on one axis need to be split, not modelled.
Principal asks
"What is the variance-to-mean ratio of that count metric, and what model did the interval assume?" If the answer is Poisson and the ratio is 4, the error bars on the dashboard are about half as wide as they should be.

Bernoulli

One yes/no trial.

The storyA single task either passes or fails. That is it. The building block everything else in pass/fail land is made from.
In eval workOne task result. One tool call succeeding. One thumbs up.
Use whenUse for a single binary outcome. It has one parameter, p. Its variance is p(1-p), which is largest at p = 0.5 and shrinks to nothing at the extremes, which is why rates near 0 or 1 are easier to pin down.
Avoid whenThere is nothing to misuse. The mistakes come one level up, in how you aggregate them.
Under the hoodBernoulli: formulas and code
\[ P(X=k) = p^k(1-p)^{1-k}, \quad k \in \{0,1\} \]
\[ E[X] = p \qquad \operatorname{Var}(X) = p(1-p) \]
import random

# GENERATE: one task result. This is the atom everything else is built from.
def one_task(p_pass: float, rng) -> int:
    return 1 if rng.random() < p_pass else 0        # 1 = passed, 0 = failed

rng = random.Random(0)
results = [one_task(0.7, rng) for _ in range(200)]  # 200 independent tasks

# SUMMARISE
n = len(results)
k = sum(results)                                    # how many passed
print(k / n)                                        # the pass rate, e.g. 0.695

# NOTE the variance: p(1-p) is largest at p = 0.5 and shrinks toward the edges.
# That is WHY a model at 50% needs more tasks to pin down than one at 95%.
for p in (0.5, 0.7, 0.95):
    print(p, "variance per task:", round(p * (1 - p), 4))

        z ^ (z >> 31)
    }
    /// Uniform on [0, 1).

}

fn round(x: f64, digits: i32) -> f64 {
    let f = 10f64.powi(digits);
    (x * f).round() / f
}

}

Binomial

Count of successes in n independent trials.

The storyRun n tasks, each passing with probability p, count the passes. The distribution of that count is binomial.
In eval workNumber of tasks passed out of 200. Number of sessions with a successful tool call, IF sessions are independent.
Use whenUse when trials are independent and share the same p. Wilson intervals are built on this.
Avoid whenDo not use when trials are not independent, which is the big one. Multiple tool calls inside one session are not independent, and treating them as binomial understates your uncertainty, sometimes by a factor of two or more.
Under the hoodBinomial: formulas and code
\[ P(X=k) = \binom{n}{k} p^k (1-p)^{n-k} \]
\[ E[X] = np \qquad \operatorname{Var}(X) = np(1-p) \]
from scipy import stats
import math

# The count of passes out of n tasks IS binomial, if the tasks are independent.
n, p = 200, 0.62
print("expected passes:", n * p)                       # 124.0
print("sd of that count:", math.sqrt(n * p * (1 - p))) # 6.86

# How likely is exactly 130 passes? And 130 or more?
print(stats.binom.pmf(130, n, p))     # exactly     -> 0.0401
print(stats.binom.sf(129, n, p))      # 130 or more -> 0.2121

# The interval you should report for an observed rate.
def wilson(k, n, z=1.96):
    p_hat = k / n
    den = 1 + z * z / n
    centre = (p_hat + z * z / (2 * n)) / den
    half = z * math.sqrt(p_hat * (1 - p_hat) / n + z * z / (4 * n * n)) / den
    return max(0.0, centre - half), min(1.0, centre + half)

print(wilson(124, 200))   # (0.5511, 0.6844)

# THE TRAP: this is only valid if tasks are independent.
# 200 tool calls from 25 sessions are NOT 200 independent trials.
/// ln Gamma(x) by the Lanczos approximation (g = 7, 9 terms).
fn ln_gamma(x: f64) -> f64 {
    const G: [f64; 9] = [
        0.999_999_999_999_809_93, 676.520_368_121_885_1, -1259.139_216_722_402_8,
        771.323_428_777_653_13, -176.615_029_162_140_59, 12.507_343_278_686_905,
        -0.138_571_095_265_720_12, 9.984_369_578_019_571_6e-6, 1.505_632_735_149_311_6e-7,
    ];
    let pi = std::f64::consts::PI;
    if x < 0.5 {
        return (pi / (pi * x).sin()).ln() - ln_gamma(1.0 - x); // reflection
    }
    let x = x - 1.0;
    let t = x + 7.5;
    let a = G[0] + (1..9).map(|i| G[i] / (x + i as f64)).sum::<f64>();
    0.5 * (2.0 * pi).ln() + (x + 0.5) * t.ln() - t + a.ln()
}

fn ln_choose(n: u64, k: u64) -> f64 {
    ln_gamma(n as f64 + 1.0) - ln_gamma(k as f64 + 1.0) - ln_gamma((n - k) as f64 + 1.0)
}

fn binom_pmf(k: u64, n: u64, p: f64) -> f64 {
    (ln_choose(n, k) + k as f64 * p.ln() + (n - k) as f64 * (1.0 - p).ln()).exp()
}

/// Survival function P(X > k): add up the upper tail.
fn binom_sf(k: u64, n: u64, p: f64) -> f64 {
    (k + 1..=n).map(|j| binom_pmf(j, n, p)).sum()
}

// The interval you should report for an observed rate.
fn wilson(k: u64, n: u64, z: f64) -> (f64, f64) {
    let (k, n) = (k as f64, n as f64);
    let p_hat = k / n;
    let den = 1.0 + z * z / n;
    let centre = (p_hat + z * z / (2.0 * n)) / den;
    let half = z * (p_hat * (1.0 - p_hat) / n + z * z / (4.0 * n * n)).sqrt() / den;
    ((centre - half).max(0.0), (centre + half).min(1.0))
}

fn main() {
    // The count of passes out of n tasks IS binomial, if the tasks are independent.
    let (n, p) = (200u64, 0.62);
    println!("expected passes: {:?}", n as f64 * p);                           // 124.0
    println!("sd of that count: {}", (n as f64 * p * (1.0 - p)).sqrt());       // 6.86

    // How likely is exactly 130 passes? And 130 or more?
    println!("{}", binom_pmf(130, n, p)); // exactly     -> 0.0401
    println!("{}", binom_sf(129, n, p));  // 130 or more -> 0.2121

    println!("{:?}", wilson(124, 200, 1.96)); // (0.5511, 0.6844)

    // THE TRAP: this is only valid if tasks are independent.
    // 200 tool calls from 25 sessions are NOT 200 independent trials.
}

Uniform

Every value in a range equally likely.

The storyNothing favours any part of the range. Flat.
In eval workP values under a true null hypothesis are uniform. That fact is what makes the multiple comparisons problem work the way it does: run 40 benchmarks with no real effect and you get 40 uniform draws, so about 2 land below 0.05.
Use whenUse as a null model, for random baselines, and for reasoning about p values.
Avoid whenAlmost no real measurement is uniform. If your data looks flat, suspect a rounding or bucketing artefact.
Under the hoodUniform: formulas and code
\[ f(x) = \frac{1}{b-a}, \quad a \le x \le b \]
\[ E[X] = \frac{a+b}{2} \qquad \operatorname{Var}(X) = \frac{(b-a)^2}{12} \]
import random

# The single most useful fact about the uniform distribution in eval work:
# p values from a TRUE NULL are uniform. That is the whole multiple
# comparisons problem in one line.
rng = random.Random(1)
suite = 40                                    # benchmarks in your standing suite
p_values = [rng.random() for _ in range(suite)]   # all nulls, no real effect

false_alarms = sum(1 for p in p_values if p < 0.05)
print(false_alarms)      # 6 with this seed; 2 on average, purely by luck

# Expected number of spurious "significant" results:
print(suite * 0.05)      # 2.0

Normal (Gaussian)

The sum of many small independent effects.

The storyWhen lots of small independent things add up, the total is normal. That is the only story it tells, and it is why normality shows up in averages and test statistics rather than in raw measurements.
In eval workAverages of large samples. Test statistics. Almost never your raw latency or token counts.
Use whenUse for averages, for differences of averages, and as the reference for QQ plots and z scores.
Avoid whenDo not assume your raw data is normal. Latency is not. Token counts are not. Counts are not. Assuming it and then using a t test on skewed data is the classic error.
Under the hoodNormal (Gaussian): formulas and code
\[ f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) \]
\[ E[X] = \mu \qquad \operatorname{Var}(X) = \sigma^2 \]
from scipy import stats
import numpy as np

# Raw eval data is almost never normal. AVERAGES of it get close.
latency = stats.lognorm.rvs(0.9, scale=3, size=5000, random_state=0)  # skewed
print(stats.skew(latency))                    # ~4.4, strongly right skewed

means = latency[:5000].reshape(-1, 50).mean(axis=1)   # averages of 50
print(stats.skew(means))                      # ~0.27 with this seed (theory ~0.67), far closer to symmetric

# The 68 / 95 / 99.7 rule, for genuinely normal data:
for k in (1, 2, 3):
    print(k, "sd covers", round(100 * (stats.norm.cdf(k) - stats.norm.cdf(-k)), 1), "%")

# Test normality rather than assuming it. Small p = not normal.
print(stats.shapiro(latency[:500]).pvalue)    # ~0 -> definitely not normal
print(stats.shapiro(means[:80]).pvalue)       # 0.35 with this seed, but across seeds this rejects
                                              # about half the time: closer to normal, not exactly normal
// A tiny inline PRNG (SplitMix64) so the snippet needs no crates.
// Its draws differ from numpy's, so the random numbers below differ from the Python's.
struct Rng(u64);

impl Rng {
    fn new(seed: u64) -> Self {
        Rng(seed)
    }
    fn next_u64(&mut self) -> u64 {
        self.0 = self.0.wrapping_add(0x9E37_79B9_7F4A_7C15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
        z ^ (z >> 31)
    }
    /// Uniform on [0, 1).
    fn random(&mut self) -> f64 {
        (self.next_u64() >> 11) as f64 / (1u64 << 53) as f64
    }
    /// Normal draw by Box-Muller.
    fn normal(&mut self, mean: f64, sd: f64) -> f64 {
        let u1 = 1.0 - self.random(); // in (0, 1], safe for ln
        let u2 = self.random();
        mean + sd * (-2.0 * u1.ln()).sqrt() * (std::f64::consts::TAU * u2).cos()
    }
}

/// ln Gamma(x) by the Lanczos approximation (g = 7, 9 terms).
fn ln_gamma(x: f64) -> f64 {
    const G: [f64; 9] = [
        0.999_999_999_999_809_93, 676.520_368_121_885_1, -1259.139_216_722_402_8,
        771.323_428_777_653_13, -176.615_029_162_140_59, 12.507_343_278_686_905,
        -0.138_571_095_265_720_12, 9.984_369_578_019_571_6e-6, 1.505_632_735_149_311_6e-7,
    ];
    let pi = std::f64::consts::PI;
    if x < 0.5 {
        return (pi / (pi * x).sin()).ln() - ln_gamma(1.0 - x); // reflection
    }
    let x = x - 1.0;
    let t = x + 7.5;
    let a = G[0] + (1..9).map(|i| G[i] / (x + i as f64)).sum::<f64>();
    0.5 * (2.0 * pi).ln() + (x + 0.5) * t.ln() - t + a.ln()
}

/// Regularized incomplete gamma functions (P, Q) = (lower, upper), P + Q = 1.
fn gamma_pq(a: f64, x: f64) -> (f64, f64) {
    if x <= 0.0 {
        return (0.0, 1.0);
    }
    let front = (-x + a * x.ln() - ln_gamma(a)).exp();
    if x < a + 1.0 {
        // power series converges fast here
        let (mut ap, mut term) = (a, 1.0 / a);
        let mut sum = term;
        while term.abs() > sum.abs() * 1e-16 {
            ap += 1.0;
            term *= x / ap;
            sum += term;
        }
        let p = sum * front;
        (p, 1.0 - p)
    } else {
        // continued fraction (modified Lentz) converges fast here
        let tiny = 1e-300;
        let (mut b, mut c) = (x + 1.0 - a, 1.0 / tiny);
        let mut d = 1.0 / b;
        let mut h = d;
        for i in 1..1000 {
            let an = -(i as f64) * (i as f64 - a);
            b += 2.0;
            d = an * d + b;
            if d.abs() < tiny { d = tiny; }
            c = b + an / c;
            if c.abs() < tiny { c = tiny; }
            d = 1.0 / d;
            h *= d * c;
            if (d * c - 1.0).abs() < 1e-16 { break; }
        }
        let q = front * h;
        (1.0 - q, q)
    }
}

/// Standard normal CDF, via the incomplete gamma function (erf(x) = P(1/2, x^2)).
fn norm_cdf(z: f64) -> f64 {
    let tail = 0.5 * gamma_pq(0.5, z * z / 2.0).1; // P(Z > |z|), accurate far out
    if z >= 0.0 { 1.0 - tail } else { tail }
}

fn mean(x: &[f64]) -> f64 {
    x.iter().sum::<f64>() / x.len() as f64
}

/// Sample skewness, as scipy.stats.skew computes it: m3 / m2^1.5.
fn skew(x: &[f64]) -> f64 {
    let m = mean(x);
    let m2 = x.iter().map(|v| (v - m).powi(2)).sum::<f64>() / x.len() as f64;
    let m3 = x.iter().map(|v| (v - m).powi(3)).sum::<f64>() / x.len() as f64;
    m3 / m2.powf(1.5)
}

fn round(x: f64, digits: i32) -> f64 {
    let f = 10f64.powi(digits);
    (x * f).round() / f
}

/// Inverse normal CDF: Acklam's rational approximation, polished by one Newton step.
fn norm_ppf(p: f64) -> f64 {
    let a = [-3.969683028665376e1, 2.209460984245205e2, -2.759285104469687e2,
             1.383577518672690e2, -3.066479806614716e1, 2.506628277459239];
    let b = [-5.447609879822406e1, 1.615858368580409e2, -1.556989798598866e2,
             6.680131188771972e1, -1.328068155288572e1];
    let c = [-7.784894002430293e-3, -3.223964580411365e-1, -2.400758277161838,
             -2.549732539343734, 4.374664141464968, 2.938163982698783];
    let d = [7.784695709041462e-3, 3.224671290700398e-1, 2.445134137142996, 3.754408661907416];
    let tail = |q: f64| (((((c[0] * q + c[1]) * q + c[2]) * q + c[3]) * q + c[4]) * q + c[5])
        / ((((d[0] * q + d[1]) * q + d[2]) * q + d[3]) * q + 1.0);
    let x = if p < 0.02425 {
        tail((-2.0 * p.ln()).sqrt())
    } else if p > 1.0 - 0.02425 {
        -tail((-2.0 * (1.0 - p).ln()).sqrt())
    } else {
        let q = p - 0.5;
        let r = q * q;
        (((((a[0] * r + a[1]) * r + a[2]) * r + a[3]) * r + a[4]) * r + a[5]) * q
            / (((((b[0] * r + b[1]) * r + b[2]) * r + b[3]) * r + b[4]) * r + 1.0)
    };
    let pdf = (-x * x / 2.0).exp() / (2.0 * std::f64::consts::PI).sqrt();
    x - (norm_cdf(x) - p) / pdf
}

fn poly(c: &[f64], x: f64) -> f64 {
    c.iter().rev().fold(0.0, |acc, &ci| acc * x + ci)
}

/// Shapiro-Wilk test (Royston's 1995 algorithm, as scipy uses), for n >= 12.
/// Returns the p value: small means "not normal".
fn shapiro_pvalue(x: &[f64]) -> f64 {
    let n = x.len();
    let nf = n as f64;
    let mut s = x.to_vec();
    s.sort_by(|a, b| a.total_cmp(b));

    // expected normal order statistics, and the weights built from them
    let m: Vec<f64> = (1..=n).map(|i| norm_ppf((i as f64 - 0.375) / (nf + 0.25))).collect();
    let mm: f64 = m.iter().map(|v| v * v).sum();
    let u = 1.0 / nf.sqrt();
    let an = m[n - 1] / mm.sqrt() + poly(&[0.0, 0.221157, -0.147981, -2.071190, 4.434685, -2.706056], u);
    let an1 = m[n - 2] / mm.sqrt() + poly(&[0.0, 0.042981, -0.293762, -1.752461, 5.682633, -3.582633], u);
    let phi = (mm - 2.0 * m[n - 1].powi(2) - 2.0 * m[n - 2].powi(2))
        / (1.0 - 2.0 * an * an - 2.0 * an1 * an1);
    let mut a: Vec<f64> = m.iter().map(|v| v / phi.sqrt()).collect();
    (a[0], a[1], a[n - 2], a[n - 1]) = (-an, -an1, an1, an);

    // W = squared correlation between the sorted data and the weights
    let xbar = mean(&s);
    let sax: f64 = a.iter().zip(&s).map(|(ai, xi)| ai * (xi - xbar)).sum();
    let ssa: f64 = a.iter().map(|v| v * v).sum();
    let ssx: f64 = s.iter().map(|v| (v - xbar).powi(2)).sum();
    let w = sax * sax / (ssa * ssx);

    // ln(1 - W) is close to normal; its mean and sd depend on ln n
    let ln_n = nf.ln();
    let mu = poly(&[-1.5861, -0.31082, -0.083751, 0.0038915], ln_n);
    let sigma = poly(&[-0.4803, -0.082676, 0.0030302], ln_n).exp();
    norm_cdf(-((1.0 - w).ln() - mu) / sigma) // upper tail
}

}

Student's t

A normal mean when you had to estimate the spread too.

The storySame bell shape but with fatter tails, because estimating the standard deviation from a small sample adds uncertainty. As n grows it converges on the normal.
In eval workSmall sample comparisons of means, under about 30 observations.

/// ln Gamma(x) by the Lanczos approximation (g = 7, 9 terms).
fn ln_gamma(x: f64) -> f64 {
    const G: [f64; 9] = [
        0.999_999_999_999_809_93, 676.520_368_121_885_1, -1259.139_216_722_402_8,
        771.323_428_777_653_13, -176.615_029_162_140_59, 12.507_343_278_686_905,
        -0.138_571_095_265_720_12, 9.984_369_578_019_571_6e-6, 1.505_632_735_149_311_6e-7,
    ];
    let pi = std::f64::consts::PI;
    if x < 0.5 {
        return (pi / (pi * x).sin()).ln() - ln_gamma(1.0 - x); // reflection
    }
    let x = x - 1.0;
    let t = x + 7.5;
    let a = G[0] + (1..9).map(|i| G[i] / (x + i as f64)).sum::<f64>();
    0.5 * (2.0 * pi).ln() + (x + 0.5) * t.ln() - t + a.ln()
}

/// Regularized incomplete beta I_x(a, b), by continued fraction (modified Lentz).
fn beta_inc(a: f64, b: f64, x: f64) -> f64 {
    if x <= 0.0 {
        return 0.0;
    }
    if x >= 1.0 {
        return 1.0;
    }
    let front = (ln_gamma(a + b) - ln_gamma(a) - ln_gamma(b) + a * x.ln() + b * (1.0 - x).ln()).exp();
    // the fraction converges fast on one side of the mean; use symmetry for the other
    if x < (a + 1.0) / (a + b + 2.0) {
        front * beta_cf(a, b, x) / a
    } else {
        1.0 - front * beta_cf(b, a, 1.0 - x) / b
    }
}

fn beta_cf(a: f64, b: f64, x: f64) -> f64 {
    let tiny = 1e-300;
    let clamp = |v: f64| if v.abs() < tiny { tiny } else { v };
    let mut c = 1.0;
    let mut d = 1.0 / clamp(1.0 - (a + b) * x / (a + 1.0));
    let mut h = d;
    for m in 1..1000 {
        let m = m as f64;
        let even = m * (b - m) * x / ((a + 2.0 * m - 1.0) * (a + 2.0 * m));
        d = 1.0 / clamp(1.0 + even * d);
        c = clamp(1.0 + even / c);
        h *= d * c;
        let odd = -(a + m) * (a + b + m) * x / ((a + 2.0 * m) * (a + 2.0 * m + 1.0));
        d = 1.0 / clamp(1.0 + odd * d);
        c = clamp(1.0 + odd / c);
        h *= d * c;
        if (d * c - 1.0).abs() < 1e-16 {
            break;
        }
    }
    h
}

fn round(x: f64, digits: i32) -> f64 {
    let f = 10f64.powi(digits);
    (x * f).round() / f
}

/// Student t CDF with df degrees of freedom, via the incomplete beta function.
fn t_cdf(t: f64, df: f64) -> f64 {
    let tail = 0.5 * beta_inc(df / 2.0, 0.5, df / (df + t * t)); // P(T > |t|)
    if t >= 0.0 { 1.0 - tail } else { tail }
}

/// Inverse t CDF by bisection: the CDF only goes up, so halve the bracket.
fn t_ppf(p: f64, df: f64) -> f64 {
    let (mut lo, mut hi) = (-100.0, 100.0);
    for _ in 0..200 {
        let mid = 0.5 * (lo + hi);
        if t_cdf(mid, df) < p { lo = mid } else { hi = mid }
    }
    0.5 * (lo + hi)
}

#[derive(Debug)]
struct TtestResult {
    statistic: f64,
    pvalue: f64,
    df: usize,
}

/// Paired t test: a one-sample t test on the per-task differences.
fn ttest_rel(a: &[f64], b: &[f64]) -> TtestResult {
    let d: Vec<f64> = a.iter().zip(b).map(|(x, y)| x - y).collect();
    let n = d.len() as f64;
    let m = d.iter().sum::<f64>() / n;
    let sd = (d.iter().map(|v| (v - m).powi(2)).sum::<f64>() / (n - 1.0)).sqrt();
    let t = m / (sd / n.sqrt());
    let pvalue = 2.0 * (1.0 - t_cdf(t.abs(), n - 1.0)); // two sided
    TtestResult { statistic: t, pvalue, df: d.len() - 1 }
}

Lognormal

The PRODUCT of many small independent effects.

The storyWhere normal comes from adding, lognormal comes from multiplying. Latency is multiplicative: a slow network multiplies with a big payload multiplies with a cold cache. So the log of latency is normal, and latency itself is lognormal.
In eval workLatency. Token counts. Session durations. Repo sizes. This is the workhorse shape of eval engineering.
Use whenUse for anything strictly positive with a long right tail. Analyse on the log scale, report percentiles in the original units. The geometric mean is its natural centre.
Avoid whenDo not report the arithmetic mean unless you need a total. Do not run a t test on it raw. And distinguish it from a genuine power law: lognormal has a finite, well behaved mean, a power law may not.
Under the hoodLognormal: formulas and code
\[ f(x) = \frac{1}{x\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(\ln x-\mu)^2}{2\sigma^2}\right) \]
\[ E[X] = e^{\mu+\sigma^2/2} \qquad \text{median} = e^{\mu} \qquad \operatorname{Var}(X) = \left(e^{\sigma^2}-1\right)e^{2\mu+\sigma^2} \]

/// Linear-interpolation quantile of SORTED data (numpy's default method).
fn quantile(sorted: &[f64], q: f64) -> f64 {
    let h = (sorted.len() - 1) as f64 * q;
    let lo = h.floor() as usize;
    let hi = (lo + 1).min(sorted.len() - 1);
    let (a, b, t) = (sorted[lo], sorted[hi], h - lo as f64);
    if t >= 0.5 { b - (b - a) * (1.0 - t) } else { a + (b - a) * t }
}

}

Exponential

Waiting time when the event rate is constant.

The storyHow long until the next event, when the chance of it happening in the next instant never changes. It is memoryless: having waited 10 seconds tells you nothing about how much longer you will wait.
In eval workTime between independent failures. Idle time between requests, roughly.
Use whenUse for waiting times with a constant hazard rate.
Avoid whenReal systems are rarely memoryless. If a request has already run 60 seconds it is probably stuck, and its remaining time is not the same as a fresh request's. Use gamma or lognormal when the hazard changes.
Under the hoodExponential: formulas and code
\[ f(x) = \lambda e^{-\lambda x}, \quad x \ge 0 \]
\[ E[X] = \frac{1}{\lambda} \qquad \operatorname{Var}(X) = \frac{1}{\lambda^2} \]

Gamma

Total time for several sequential steps.

The storyAdd up several exponential waits and you get a gamma. Shape parameter = how many steps.
In eval workEnd to end latency through a multi stage pipeline. Total time for an agent loop with several tool calls.
Use whenUse for sums of waiting times. With shape 1 it IS exponential; with large shape it approaches normal.
Avoid whenNeeds the steps to be independent and similarly scaled. A pipeline with one dominant slow stage is not gamma, it is basically that stage's own distribution.
Under the hoodGamma: formulas and code
\[ f(x) = \frac{\lambda^k x^{k-1} e^{-\lambda x}}{\Gamma(k)} \]
\[ E[X] = \frac{k}{\lambda} \qquad \operatorname{Var}(X) = \frac{k}{\lambda^2} \]

# Sum of k exponentials with the same rate IS a gamma with shape k.

total = stages.sum(axis=1)

impl Rng {
    /// Gamma(shape, scale) draw, Marsaglia-Tsang method (shape >= 1).
    fn gamma(&mut self, shape: f64, scale: f64) -> f64 {
        let d = shape - 1.0 / 3.0;
        let c = 1.0 / (9.0 * d).sqrt();
        loop {
            let z = self.normal(0.0, 1.0);
            let v = (1.0 + c * z).powi(3);
            if v > 0.0 && self.random().ln() < 0.5 * z * z + d - d * v + d * v.ln() {
                return d * v * scale;
            }
        }
    }
}

fn digamma(mut x: f64) -> f64 {
    let mut r = 0.0;
    while x < 6.0 {
        r -= 1.0 / x; // psi(x) = psi(x + 1) - 1/x
        x += 1.0;
    }
    let f = 1.0 / (x * x); // asymptotic series for large x
    r + x.ln() - 0.5 / x - f * (1.0 / 12.0 - f * (1.0 / 120.0 - f * (1.0 / 252.0 - f / 240.0)))
}

/// Maximum likelihood gamma shape with loc fixed at 0:
/// solve ln(k) - digamma(k) = ln(mean) - mean(ln x). The left side falls as k grows.
fn gamma_fit_shape(x: &[f64]) -> f64 {
    let s = mean(x).ln() - x.iter().map(|v| v.ln()).sum::<f64>() / x.len() as f64;
    let (mut lo, mut hi) = (1e-3_f64, 1e3_f64);
    for _ in 0..200 {
        let mid = (lo * hi).sqrt();
        if mid.ln() - digamma(mid) > s { lo = mid } else { hi = mid }
    }
    (lo * hi).sqrt()
}

Poisson

Count of events in a fixed window, at a constant rate.

The storyEvents happen independently at a steady average rate; you count how many landed in one window. Its defining property: variance equals the mean.
In eval workRequests per minute during steady traffic. Errors per hour when nothing unusual is happening.
Use whenUse when your variance/mean ratio comes out near 1.
Avoid whenCheck that ratio first, because it usually is not near 1. Tool calls per session run 3 to 6, not 1. Assuming Poisson there makes your intervals roughly sqrt(ratio) times too narrow, and you will call noise a change.
Under the hoodPoisson: formulas and code
\[ P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!} \]
\[ E[X] = \lambda \qquad \operatorname{Var}(X) = \lambda \qquad \frac{\operatorname{Var}}{E} = 1 \]

Negative binomial

Counts when the rate itself varies.

The storyA mixture of Poissons with different rates is a negative binomial. Easy tasks take two tool calls, hard ones take twenty. The rate is not constant across tasks, so the counts spread far wider than Poisson allows.
In eval workTool calls per session. Turns per conversation. Retries per task. Nearly every count in agent evaluation.
Use whenUse whenever variance/mean is well above 1, which for agent counts is essentially always.
Avoid whenIt has one more parameter than Poisson, so it needs a bit more data. If you only need an interval rather than a model, bootstrapping quantiles is simpler and just as defensible.
Under the hoodNegative binomial: formulas and code
\[ P(X=k) = \binom{k+r-1}{k}(1-p)^k p^r \]
\[ E[X] = \mu \qquad \operatorname{Var}(X) = \mu + \frac{\mu^2}{r} \;>\; \mu \]

        z ^ (z >> 31)

    fn random(&mut self) -> f64 {

    }
    /// Normal draw by Box-Muller.
    fn normal(&mut self, mean: f64, sd: f64) -> f64 {
        let u1 = 1.0 - self.random(); // in (0, 1], safe for ln
        let u2 = self.random();
        mean + sd * (-2.0 * u1.ln()).sqrt() * (std::f64::consts::TAU * u2).cos()
    }
}

impl Rng {
    /// Gamma(shape, scale) draw, Marsaglia-Tsang method (shape >= 1).
    fn gamma(&mut self, shape: f64, scale: f64) -> f64 {
        let d = shape - 1.0 / 3.0;
        let c = 1.0 / (9.0 * d).sqrt();
        loop {
            let z = self.normal(0.0, 1.0);
            let v = (1.0 + c * z).powi(3);
            if v > 0.0 && self.random().ln() < 0.5 * z * z + d - d * v + d * v.ln() {
                return d * v * scale;
            }
        }
    }
}

/// ln Gamma(x) by the Lanczos approximation (g = 7, 9 terms).
fn ln_gamma(x: f64) -> f64 {
    const G: [f64; 9] = [
        0.999_999_999_999_809_93, 676.520_368_121_885_1, -1259.139_216_722_402_8,
        771.323_428_777_653_13, -176.615_029_162_140_59, 12.507_343_278_686_905,
        -0.138_571_095_265_720_12, 9.984_369_578_019_571_6e-6, 1.505_632_735_149_311_6e-7,
    ];
    let pi = std::f64::consts::PI;
    if x < 0.5 {
        return (pi / (pi * x).sin()).ln() - ln_gamma(1.0 - x); // reflection
    }
    let x = x - 1.0;
    let t = x + 7.5;
    let a = G[0] + (1..9).map(|i| G[i] / (x + i as f64)).sum::<f64>();
    0.5 * (2.0 * pi).ln() + (x + 0.5) * t.ln() - t + a.ln()
}

fn poisson_pmf(k: u64, mu: f64) -> f64 {
    (k as f64 * mu.ln() - mu - ln_gamma(k as f64 + 1.0)).exp()
}

/// Negative binomial pmf: failures before the r-th success, success chance p.
fn nbinom_pmf(k: u64, r: f64, p: f64) -> f64 {
    let k = k as f64;
    (ln_gamma(k + r) - ln_gamma(r) - ln_gamma(k + 1.0) + r * p.ln() + k * (1.0 - p).ln()).exp()
}

/// Survival function P(X > k): add up the upper tail (far enough that the rest is negligible).
fn sf(pmf: impl Fn(u64) -> f64, k: u64) -> f64 {
    (k + 1..k + 2000).map(pmf).sum()
}

    println!("NegBinom says: {}", sf(|k| nbinom_pmf(k, r, r / (r + mu)), 19)); // 0.018 (real)

Beta

A distribution over a RATE you are uncertain about.

The storyEverything else here describes data. Beta describes your belief about a probability. After seeing 8 passes and 4 fails, Beta(8,4) is the shape of your uncertainty about the true pass rate. More evidence, tighter shape.
In eval workUncertainty about a pass rate. Priors when you have very few tasks. Smoothing a rate estimated from a handful of observations.
Use whenUse for reasoning about rates, especially with small samples. It is the natural partner to the binomial.
Avoid whenIt is a belief, not a measurement. Do not report a Beta as if it described your data, and be explicit about any prior you chose, because with small n the prior is doing real work.
Under the hoodBeta: formulas and code
\[ f(x) = \frac{x^{\alpha-1}(1-x)^{\beta-1}}{B(\alpha,\beta)}, \quad 0 \le x \le 1 \]
\[ E[X] = \frac{\alpha}{\alpha+\beta} \qquad \operatorname{Var}(X) = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)} \]

/// Regularized incomplete beta I_x(a, b), by continued fraction (modified Lentz).
fn beta_inc(a: f64, b: f64, x: f64) -> f64 {
    if x <= 0.0 {
        return 0.0;
    }
    if x >= 1.0 {
        return 1.0;
    }
    let front = (ln_gamma(a + b) - ln_gamma(a) - ln_gamma(b) + a * x.ln() + b * (1.0 - x).ln()).exp();
    // the fraction converges fast on one side of the mean; use symmetry for the other
    if x < (a + 1.0) / (a + b + 2.0) {
        front * beta_cf(a, b, x) / a
    } else {
        1.0 - front * beta_cf(b, a, 1.0 - x) / b
    }
}

fn beta_cf(a: f64, b: f64, x: f64) -> f64 {
    let tiny = 1e-300;
    let clamp = |v: f64| if v.abs() < tiny { tiny } else { v };
    let mut c = 1.0;
    let mut d = 1.0 / clamp(1.0 - (a + b) * x / (a + 1.0));
    let mut h = d;
    for m in 1..1000 {
        let m = m as f64;
        let even = m * (b - m) * x / ((a + 2.0 * m - 1.0) * (a + 2.0 * m));
        d = 1.0 / clamp(1.0 + even * d);
        c = clamp(1.0 + even / c);
        h *= d * c;
        let odd = -(a + m) * (a + b + m) * x / ((a + 2.0 * m) * (a + 2.0 * m + 1.0));
        d = 1.0 / clamp(1.0 + odd * d);
        c = clamp(1.0 + odd / c);
        h *= d * c;
        if (d * c - 1.0).abs() < 1e-16 {
            break;
        }
    }
    h
}

fn round(x: f64, digits: i32) -> f64 {
    let f = 10f64.powi(digits);
    (x * f).round() / f
}

struct Beta {
    a: f64,
    b: f64,
}

impl Beta {
    fn mean(&self) -> f64 {
        self.a / (self.a + self.b)
    }
    fn cdf(&self, x: f64) -> f64 {
        beta_inc(self.a, self.b, x)
    }
    /// Inverse CDF by bisection: the CDF only goes up, so halve the bracket.
    fn ppf(&self, p: f64) -> f64 {
        let (mut lo, mut hi) = (0.0, 1.0);
        for _ in 0..100 {
            let mid = 0.5 * (lo + hi);
            if self.cdf(mid) < p { lo = mid } else { hi = mid }
        }
        0.5 * (lo + hi)
    }
    /// Central interval holding `level` of the probability.
    fn interval(&self, level: f64) -> (f64, f64) {
        (self.ppf((1.0 - level) / 2.0), self.ppf((1.0 + level) / 2.0))
    }
}

        let (lo, hi) = Beta { a: 1.0 + k, b: 1.0 + n as f64 - k }.interval(0.95);
        println!("{} tasks -> {} wide", n, round(hi - lo, 3));
    }

    // Probability model A truly beats a 0.60 baseline, given the data:
    println!("{}", 1.0 - Beta { a: 1.0 + 8.0, b: 1.0 + 4.0 }.cdf(0.60)); // 0.647 - genuinely unsure

fn gamma_pq(a: f64, x: f64) -> (f64, f64) {
    if x <= 0.0 {
        return (0.0, 1.0);
    }
    let front = (-x + a * x.ln() - ln_gamma(a)).exp();
    if x < a + 1.0 {
        // power series converges fast here
        let (mut ap, mut term) = (a, 1.0 / a);
        let mut sum = term;
        while term.abs() > sum.abs() * 1e-16 {
            ap += 1.0;
            term *= x / ap;
            sum += term;
        }
        let p = sum * front;
        (p, 1.0 - p)
    } else {
        // continued fraction (modified Lentz) converges fast here
        let tiny = 1e-300;
        let (mut b, mut c) = (x + 1.0 - a, 1.0 / tiny);
        let mut d = 1.0 / b;
        let mut h = d;
        for i in 1..1000 {
            let an = -(i as f64) * (i as f64 - a);
            b += 2.0;
            d = an * d + b;
            if d.abs() < tiny { d = tiny; }
            c = b + an / c;
            if c.abs() < tiny { c = tiny; }
            d = 1.0 / d;
            h *= d * c;
            if (d * c - 1.0).abs() < 1e-16 { break; }
        }
        let q = front * h;
        (1.0 - q, q)
    }
}

fn ln_choose(n: u64, k: u64) -> f64 {
    ln_gamma(n as f64 + 1.0) - ln_gamma(k as f64 + 1.0) - ln_gamma((n - k) as f64 + 1.0)
}

/// Chi square test of independence on an r x c table of counts.
/// Returns (statistic, p value, degrees of freedom, expected counts).
fn chi2_contingency(observed: &[Vec<f64>]) -> (f64, f64, usize, Vec<Vec<f64>>) {
    let row: Vec<f64> = observed.iter().map(|r| r.iter().sum()).collect();
    let col: Vec<f64> = (0..observed[0].len()).map(|j| observed.iter().map(|r| r[j]).sum()).collect();
    let total: f64 = row.iter().sum();
    let expected: Vec<Vec<f64>> = row.iter().map(|ri| col.iter().map(|cj| ri * cj / total).collect()).collect();
    let chi2: f64 = observed.iter().flatten().zip(expected.iter().flatten())
        .map(|(o, e)| (o - e).powi(2) / e)
        .sum();
    let dof = (row.len() - 1) * (col.len() - 1);
    let p = gamma_pq(dof as f64 / 2.0, chi2 / 2.0).1; // chi square upper tail
    (chi2, p, dof, expected)
}

#[derive(Debug)]
struct SignificanceResult {
    statistic: f64, // the sample odds ratio
    pvalue: f64,
}

/// Two-sided Fisher exact test on [[a, b], [c, d]]: add up every table with the
/// same margins that is no more likely than the one observed.
fn fisher_exact(t: [[u64; 2]; 2]) -> SignificanceResult {
    let [[a, b], [c, d]] = t;
    let (row1, col1, n) = (a + b, a + c, a + b + c + d);
    let ln_pmf = |x: u64| ln_choose(row1, x) + ln_choose(n - row1, col1 - x) - ln_choose(n, col1);
    let cutoff = ln_pmf(a) + 1e-7_f64.ln_1p(); // small tolerance for rounding
    let lo = col1.saturating_sub(n - row1);
    let hi = row1.min(col1);
    let p: f64 = (lo..=hi).map(ln_pmf).filter(|&l| l <= cutoff).map(f64::exp).sum();
    SignificanceResult { statistic: (a * d) as f64 / (b * c) as f64, pvalue: p.min(1.0) }
}

fn main() {
    // You rarely MEASURE something chi square. You compute a statistic that follows it.
    // Example: are failure reasons distributed the same across two models?

impl Rng {
    fn new(seed: u64) -> Self {

    }
    fn next_u64(&mut self) -> u64 {
        self.0 = self.0.wrapping_add(0x9E37_79B9_7F4A_7C15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);

        z ^ (z >> 31)
    }

        (self.next_u64() >> 11) as f64 / (1u64 << 53) as f64
    }
    /// Normal draw by Box-Muller.
    fn normal(&mut self, mean: f64, sd: f64) -> f64 {
        let u1 = 1.0 - self.random(); // in (0, 1], safe for ln
        let u2 = self.random();
        mean + sd * (-2.0 * u1.ln()).sqrt() * (std::f64::consts::TAU * u2).cos()
    }

/// ln Gamma(x) by the Lanczos approximation (g = 7, 9 terms).
fn ln_gamma(x: f64) -> f64 {
    const G: [f64; 9] = [
        0.999_999_999_999_809_93, 676.520_368_121_885_1, -1259.139_216_722_402_8,
        771.323_428_777_653_13, -176.615_029_162_140_59, 12.507_343_278_686_905,
        -0.138_571_095_265_720_12, 9.984_369_578_019_571_6e-6, 1.505_632_735_149_311_6e-7,
    ];
    let pi = std::f64::consts::PI;
    if x < 0.5 {
        return (pi / (pi * x).sin()).ln() - ln_gamma(1.0 - x); // reflection
    }
    let x = x - 1.0;
    let t = x + 7.5;
    let a = G[0] + (1..9).map(|i| G[i] / (x + i as f64)).sum::<f64>();
    0.5 * (2.0 * pi).ln() + (x + 0.5) * t.ln() - t + a.ln()
}

/// Regularized incomplete gamma functions (P, Q) = (lower, upper), P + Q = 1.
fn gamma_pq(a: f64, x: f64) -> (f64, f64) {
    if x <= 0.0 {
        return (0.0, 1.0);
    }
    let front = (-x + a * x.ln() - ln_gamma(a)).exp();
    if x < a + 1.0 {
        // power series converges fast here
        let (mut ap, mut term) = (a, 1.0 / a);
        let mut sum = term;
        while term.abs() > sum.abs() * 1e-16 {
            ap += 1.0;
            term *= x / ap;
            sum += term;
        }
        let p = sum * front;
        (p, 1.0 - p)
    } else {
        // continued fraction (modified Lentz) converges fast here
        let tiny = 1e-300;
        let (mut b, mut c) = (x + 1.0 - a, 1.0 / tiny);
        let mut d = 1.0 / b;
        let mut h = d;
        for i in 1..1000 {
            let an = -(i as f64) * (i as f64 - a);
            b += 2.0;
            d = an * d + b;
            if d.abs() < tiny { d = tiny; }
            c = b + an / c;
            if c.abs() < tiny { c = tiny; }
            d = 1.0 / d;
            h *= d * c;
            if (d * c - 1.0).abs() < 1e-16 { break; }
        }
        let q = front * h;
        (1.0 - q, q)
    }
}

/// Regularized incomplete beta I_x(a, b), by continued fraction (modified Lentz).
fn beta_inc(a: f64, b: f64, x: f64) -> f64 {
    if x <= 0.0 {
        return 0.0;
    }
    if x >= 1.0 {
        return 1.0;
    }
    let front = (ln_gamma(a + b) - ln_gamma(a) - ln_gamma(b) + a * x.ln() + b * (1.0 - x).ln()).exp();
    // the fraction converges fast on one side of the mean; use symmetry for the other
    if x < (a + 1.0) / (a + b + 2.0) {
        front * beta_cf(a, b, x) / a
    } else {
        1.0 - front * beta_cf(b, a, 1.0 - x) / b
    }
}

fn beta_cf(a: f64, b: f64, x: f64) -> f64 {
    let tiny = 1e-300;
    let clamp = |v: f64| if v.abs() < tiny { tiny } else { v };
    let mut c = 1.0;
    let mut d = 1.0 / clamp(1.0 - (a + b) * x / (a + 1.0));
    let mut h = d;
    for m in 1..1000 {
        let m = m as f64;
        let even = m * (b - m) * x / ((a + 2.0 * m - 1.0) * (a + 2.0 * m));
        d = 1.0 / clamp(1.0 + even * d);
        c = clamp(1.0 + even / c);
        h *= d * c;
        let odd = -(a + m) * (a + b + m) * x / ((a + 2.0 * m) * (a + 2.0 * m + 1.0));
        d = 1.0 / clamp(1.0 + odd * d);
        c = clamp(1.0 + odd / c);
        h *= d * c;
        if (d * c - 1.0).abs() < 1e-16 {
            break;
        }
    }
    h
}

fn mean(x: &[f64]) -> f64 {
    x.iter().sum::<f64>() / x.len() as f64
}

/// One-way ANOVA. Returns (F, p value).
fn f_oneway(groups: &[&[f64]]) -> (f64, f64) {
    let all: Vec<f64> = groups.concat();
    let grand = mean(&all);
    let ss_between: f64 = groups.iter().map(|g| g.len() as f64 * (mean(g) - grand).powi(2)).sum();
    let ss_within: f64 = groups.iter()
        .map(|g| { let m = mean(g); g.iter().map(|v| (v - m).powi(2)).sum::<f64>() })
        .sum();
    let (df_b, df_w) = ((groups.len() - 1) as f64, (all.len() - groups.len()) as f64);
    let f = (ss_between / df_b) / (ss_within / df_w);
    let p = beta_inc(df_w / 2.0, df_b / 2.0, df_w / (df_w + df_b * f)); // F upper tail
    (f, p)
}

struct KruskalResult {
    statistic: f64,
    pvalue: f64,
}

/// Kruskal-Wallis H test: ANOVA on ranks, so skew and outliers do not matter.
fn kruskal(groups: &[&[f64]]) -> KruskalResult {
    // pool, sort, and give tied values their average rank
    let mut pooled: Vec<(f64, usize)> = groups.iter().enumerate()
        .flat_map(|(gi, g)| g.iter().map(move |&v| (v, gi)))
        .collect();
    pooled.sort_by(|a, b| a.0.total_cmp(&b.0));
    let n = pooled.len() as f64;
    let mut rank_sum = vec![0.0; groups.len()];
    let mut ties = 0.0; // for the tie correction
    let mut i = 0;
    while i < pooled.len() {
        let mut j = i;
        while j + 1 < pooled.len() && pooled[j + 1].0 == pooled[i].0 {
            j += 1;
        }
        let avg_rank = (i + j) as f64 / 2.0 + 1.0;
        for item in &pooled[i..=j] {
            rank_sum[item.1] += avg_rank;
        }
        let t = (j - i + 1) as f64;
        ties += t * t * t - t;
        i = j + 1;
    }
    let h: f64 = 12.0 / (n * (n + 1.0))
        * groups.iter().zip(&rank_sum).map(|(g, r)| r * r / g.len() as f64).sum::<f64>()
        - 3.0 * (n + 1.0);
    let h = h / (1.0 - ties / (n * n * n - n));
    let df = (groups.len() - 1) as f64;
    KruskalResult { statistic: h, pvalue: gamma_pq(df / 2.0, h / 2.0).1 } // chi square upper tail
}

Pareto / power law

Scale free: no typical size.

The storyThe heaviest tail you will meet in practice. Doubling the value divides its frequency by a constant, which produces a straight line on log-log axes. Depending on the tail index, the mean and even the variance may not converge.
In eval workRepo sizes. File sizes. Occasionally session lengths in a long tailed product.
Use whenUse when a log-log plot is straight and the tail refuses to settle down.
Avoid whenNever report a mean for a genuine power law. It may not exist, and your sample mean will keep drifting as you collect more data. Percentiles and log scales only. Distinguish carefully from lognormal, which looks similar but is much better behaved.

\[ P(X > x) = \left(\frac{x_m}{x}\right)^{\alpha} \]

fn chisquare(observed: &[f64], expected: &[f64]) -> PowerDivergenceResult {
    let statistic: f64 = observed.iter().zip(expected).map(|(o, e)| (o - e).powi(2) / e).sum();
    let dof = (observed.len() - 1) as f64;
    PowerDivergenceResult { statistic, pvalue: gamma_pq(dof / 2.0, statistic / 2.0).1 }
}

Mixture

Two or more populations sharing an axis.

The storyNot a distribution family so much as a warning. Any two distributions can be blended, and the result often looks like one distribution with strange outliers.
In eval workCache hits and cold starts. Retried and first-try requests. Easy and hard task categories. Very common and very often missed.
Use whenUse it as a diagnosis, not a model. When you see two humps, go find the variable that separates them.
Avoid whenDo not fit a single distribution to a mixture and then report its mean or median. The median can land in the empty valley between the humps, describing a case that never occurs.

// A tiny inline PRNG (SplitMix64) so the snippet needs no crates.
// Its draws differ from numpy's, so the random numbers below differ from the Python's.
struct Rng(u64);

impl Rng {
    fn new(seed: u64) -> Self {
        Rng(seed)
    }
    fn next_u64(&mut self) -> u64 {
        self.0 = self.0.wrapping_add(0x9E37_79B9_7F4A_7C15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
        z ^ (z >> 31)
    }
    /// Uniform on [0, 1).
    fn random(&mut self) -> f64 {
        (self.next_u64() >> 11) as f64 / (1u64 << 53) as f64
    }
    /// Normal draw by Box-Muller.
    fn normal(&mut self, mean: f64, sd: f64) -> f64 {
        let u1 = 1.0 - self.random(); // in (0, 1], safe for ln
        let u2 = self.random();
        mean + sd * (-2.0 * u1.ln()).sqrt() * (std::f64::consts::TAU * u2).cos()
    }
}

fn mean(x: &[f64]) -> f64 {
    x.iter().sum::<f64>() / x.len() as f64
}

fn median(x: &[f64]) -> f64 {
    let mut s = x.to_vec();
    s.sort_by(|a, b| a.total_cmp(b));
    let n = s.len();
    if n % 2 == 1 { s[n / 2] } else { (s[n / 2 - 1] + s[n / 2]) / 2.0 }
}

fn normal_pdf(x: f64, mu: f64, var: f64) -> f64 {
    (-(x - mu).powi(2) / (2.0 * var)).exp() / (2.0 * std::f64::consts::PI * var).sqrt()
}

/// Fit a 1-D Gaussian mixture with k components by EM (fitting by hand).
/// Returns the BIC: -2 log likelihood + parameters * ln n. Lower is better.
fn gmm_bic(x: &[f64], k: usize) -> f64 {
    let n = x.len();
    let mut s = x.to_vec();
    s.sort_by(|a, b| a.total_cmp(b));
    // start the means spread across the data, each component with the overall variance
    let mut mu: Vec<f64> = (0..k).map(|j| s[(2 * j + 1) * n / (2 * k)]).collect();
    let m = mean(x);
    let mut var = vec![x.iter().map(|v| (v - m).powi(2)).sum::<f64>() / n as f64; k];
    let mut w = vec![1.0 / k as f64; k];
    let mut resp = vec![vec![0.0; k]; n];
    let mut loglik = f64::NEG_INFINITY;

    for _ in 0..500 {
        // E step: how much each component "owns" each point
        let mut ll = 0.0;
        for (i, &xi) in x.iter().enumerate() {
            let dens: Vec<f64> = (0..k).map(|j| w[j] * normal_pdf(xi, mu[j], var[j])).collect();
            let total: f64 = dens.iter().sum();
            ll += total.ln();
            for j in 0..k {
                resp[i][j] = dens[j] / total;
            }
        }
        // M step: refit each component to the points it owns
        for j in 0..k {
            let nj: f64 = resp.iter().map(|r| r[j]).sum();
            w[j] = nj / n as f64;
            mu[j] = x.iter().zip(&resp).map(|(xi, r)| r[j] * xi).sum::<f64>() / nj;
            var[j] = x.iter().zip(&resp).map(|(xi, r)| r[j] * (xi - mu[j]).powi(2)).sum::<f64>() / nj + 1e-6;
        }
        let done = (ll - loglik).abs() / (n as f64) < 1e-6; // average log likelihood has settled
        loglik = ll;
        if done {
            break;
        }
    }
    let params = (3 * k - 1) as f64; // k means, k variances, k - 1 free weights
    -2.0 * loglik + params * (n as f64).ln()
}

fn main() {
    let mut rng0 = Rng::new(0);
    let mut rng1 = Rng::new(1);
    let mut lat: Vec<f64> = (0..2200).map(|_| rng0.normal(1.2, 0.3)).collect(); // cached
    lat.extend((0..800).map(|_| rng1.normal(6.5, 1.5)));                       // cold start

    // DIAGNOSIS, not a model. Two components fit far better than one?

    println!("BIC two components: {}", gmm_bic(&logs, 2).round()); // much lower -> mixture
